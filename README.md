# 矿石雷达 (Ore Radar)

一个《我的世界》基岩版 Addon，能够探测并标记玩家周围的稀有矿石，帮助玩家高效搜寻矿物。

## 功能特性

- 多种矿石雷达：紫水晶、铁、金、钻石矿石雷达
- 深度搜索芯片，配合雷达使用提升搜索能力
- 自动检测矿石（按 `typeId` 匹配）
- 支持白名单 / 黑名单名单类型
- 可在表单界面中自定义扫描的矿石类型
- 雷达拥有耐久与冷却机制，平衡游戏体验

## 包结构

```
矿石雷达_BP/     # 行为包   (Behavior Pack)
矿石雷达_RP/     # 资源包   (Resource Pack)
```

- `矿石雷达_BP/`：包含物品定义、合成配方、雷达脚本逻辑
- `矿石雷达_RP/`：包含纹理、物品图标、本地化文案（中 / 英）

## 使用方法

1. 将 `矿石雷达_BP` 与 `矿石雷达_RP` 两个文件夹分别装入游戏的行为包和资源包。
2. 在游戏中通过合成配方制作对应的矿石雷达。
3. 手持雷达右击使用，即可在周围指定范围内搜索并标记目标矿石。

## 构建

行为包脚本采用 TypeScript 编写，编译后在 `scripts/` 目录生成 JavaScript。

```bash
# 在 矿石雷达_BP 目录下安装依赖
npm install

# 编译 TypeScript
npm run build

# 持续监视并编译
npm run watch
```

## 本地化

资源包包含中英文两套语言文件：

- `texts/zh_CN.lang` — 简体中文
- `texts/en_US.lang` — English
